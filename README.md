
# SWISH 🏀

**Swish** is a basketball arcade game built with Unity and C#.

## Features
- Interactive basketball shooting mechanics
- Aiming and shooting gameplay
- Moving hoop mechanics
- Score tracking and lives system
- Multiple game modes and customization
- Mobile-friendly interface

## Built With
- Unity
- C#
- GitHub

## Developer
Created as an independent game development project.
